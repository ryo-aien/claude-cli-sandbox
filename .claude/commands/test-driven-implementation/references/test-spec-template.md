# TEST_SPEC.md テンプレート

以下のテンプレートを使ってプロジェクトルートに `TEST_SPEC.md` を作成する。

```markdown
# テスト仕様書

## プロジェクト情報
- プロジェクト名: (プロジェクト名)
- テスト作成日: (YYYY-MM-DD)
- テスト実行環境: (ローカル / Docker / その他)

## テスト結果サマリー
| 項目 | 値 |
|------|-----|
| 総テスト数 | X |
| Pass | X |
| Fail | 0 |
| 修正回数 | X回 |
| 最終実行日時 | YYYY-MM-DD HH:MM |

## テスト項目

### 正常系テスト

| ID | テスト内容 | 実行手順 | 期待される結果 | 結果 | 実行日時 | 備考 |
|----|-----------|---------|--------------|------|---------|------|
| T001 | (テスト内容) | (コマンドまたは手順) | (期待結果) | - | - | - |
| T002 | (テスト内容) | (コマンドまたは手順) | (期待結果) | - | - | - |

### 異常系テスト

| ID | テスト内容 | 実行手順 | 期待される結果 | 結果 | 実行日時 | 備考 |
|----|-----------|---------|--------------|------|---------|------|
| T010 | (テスト内容) | (コマンドまたは手順) | (期待結果) | - | - | - |

### 境界値テスト

| ID | テスト内容 | 実行手順 | 期待される結果 | 結果 | 実行日時 | 備考 |
|----|-----------|---------|--------------|------|---------|------|
| T020 | (テスト内容) | (コマンドまたは手順) | (期待結果) | - | - | - |

## 修正履歴

| 修正回 | 対象テストID | 修正内容 | 修正ファイル | 結果 |
|--------|------------|---------|------------|------|
| 1 | (ID) | (修正内容) | (ファイル名) | Pass |
```

## ID採番ルール

- 正常系: T001〜T009
- 異常系: T010〜T019
- 境界値: T020〜T029
- 統合テスト: T030〜T039

項目が多い場合は適宜拡張する。
